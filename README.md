# Student Management System

## Description
A simple React application that displays student details using reusable components, JSX, props, and inline CSS styling.

## Features
- Displays student name, department, and year.
- Uses reusable `StudentProfile` components.
- Includes a styled header and footer.
- Uses props to pass student details.
- Applies inline CSS for styling.

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm run dev
   ```
5. Open the local URL displayed in the terminal.
